## 📌 About

**Empty but Live** is a Week 04 assignment from the **General AI Fluency** track.

The objective is simple:

> **Start with nothing and ship something that is actually live on the internet.**

Instead of spending time building a complete website, this milestone focuses on creating the project foundation, connecting it to GitHub, deploying it, and verifying the live URL on a second device.

---

## 🎯 Assignment Goals

* ✅ Create the project using the selected stack
* ✅ Create and connect a GitHub repository
* ✅ Build a near-blank homepage
* ✅ Deploy the project publicly
* ✅ Verify the website on a second device
* ✅ Prepare project materials for the next build phase
